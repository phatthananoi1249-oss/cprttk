# ⏱️ MEGA Code Clock — ระบบบันทึกเวลาปฏิบัติงานและกิจกรรม

ระบบบันทึกเวลาสไตล์ **MEGA Code Clock** ออกแบบ UI ระดับมืออาชีพโทนสี **Navy Blue & White** (`#0b2545`, `#13325f`, `#0c4a8e`, `#ffffff`, `#eef2f6`) รองรับการใช้งานทั้งคอมพิวเตอร์และโทรศัพท์มือถือ พร้อมเชื่อมต่อ **Google Sheets** เป็นฐานข้อมูลอย่างถาวร

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **นาฬิกา Real-Time แบบเรียลไทม์**:
   - หน้าจอแสดงเวลาปัจจุบันขนาดใหญ่คมชัด (HH:mm:ss) พร้อมระบุวันที่และปี พ.ศ. ภาษาไทย
   - ระบบจับเวลาประจำรอบ (Round Stopwatch) นับเวลาต่อเนื่องตั้งแต่เริ่มรอบ
2. **การบันทึกเวลาผู้เข้าร่วม (Time Stamp Entry)**:
   - กรอก **ชื่อ**, **นามสกุล**, **รหัส/สังกัด**, **ประเภทการลงเวลา** (เข้างาน, จุดเช็คพอยท์, ออกงาน, เหตุการณ์) และ **หมายเหตุ**
   - ปุ่มใหญ่ **"⚡ กดบันทึกเวลาอัตโนมัติ"** ทำงานทันทีเมื่อกด หรือกดปุ่ม **Enter** จากคีย์บอร์ด
   - มีระบบจำลองเสียง Beep / Chime (Web Audio API) เมื่อแสตมป์เวลาสำเร็จ
3. **ระบบจัดการรอบ (Round Management)**:
   - รองรับผู้เข้าร่วมหลายคนในแต่ละรอบ
   - **ปุ่ม "เริ่มรอบใหม่" (New Round)**: สร้างรอบถัดไปอัตโนมัติหรือตั้งชื่อเอง **โดยไม่ลบข้อมูลของรอบก่อนหน้า**
   - ข้อมูลของทุกรอบยังคงถูกบันทึกและตรวจสอบย้อนหลังได้ตลอดเวลา
   - มีแผง **"ผู้เข้าร่วมในรอบนี้ (Quick Roster)"** แตะครั้งเดียวเพื่อแสตมป์เวลาซ้ำให้คนที่เคยลงชื่อไว้ได้ทันที
4. **ตารางประวัติและการจัดการข้อมูล (History & Management)**:
   - ตารางแสดงข้อมูลเรียงตามเวลา (เลือกสลับเวลาล่าสุดก่อน หรือเวลาแรกเริ่มก่อนได้)
   - ช่องค้นหาอัจฉริยะ (ค้นหาตามชื่อ, สกุล, รหัส, รอบ, หรือหมายเหตุ)
   - ตัวกรองแยกรอบ และแยกประเภทการลงเวลา
   - **ระบบแก้ไขข้อมูล (Edit Modal)**: แก้ไขชื่อ, รอบ, เวลา, และหมายเหตุได้ตลอดเวลา
   - **ระบบลบข้อมูล (Delete)** พร้อมการยืนยัน
5. **การส่งออกข้อมูล (Export)**:
   - **📊 Excel (.csv UTF-8 BOM)**: เปิดบน Microsoft Excel ได้ทันที สระและภาษาไทยไม่เพี้ยน ไม่เป็นภาษาต่างดาว
   - **🖨️ PDF / พิมพ์รายงาน A4**: สร้างหน้าพิมพ์เอกสารทางการ พร้อมหัวกระดาษ สถิติสรุป ตารางผลลัพธ์ และช่องลงลายมือชื่อผู้บันทึก/ผู้รับรอง
6. **ฐานข้อมูล Google Sheets อย่างถาวร**:
   - ส่งข้อมูลเข้า Google Sheets แบบ Real-time ทันทีที่บันทึก
   - รองรับ **Offline-first**: บันทึกลงเครื่อง (`localStorage`) ก่อนอัตโนมัติ ใช้งานได้แม้ไม่มีอินเทอร์เน็ต และมีปุ่ม **"ซิงค์ข้อมูลค้างส่ง"** เมื่อออนไลน์

## ☁️ วิธีเชื่อมต่อ Google Sheets เป็นฐานข้อมูล

คุณสามารถเชื่อมต่อ Google Sheets เพื่อให้ข้อมูลถูกบันทึกอย่างถาวรในคลาวด์ได้ง่ายๆ ใน 2 นาที:

### 1. สร้าง Google Sheets
1. เปิด [Google Sheets](https://sheets.new) เปล่าขึ้นมา 1 ไฟล์ ตั้งชื่อตามต้องการ เช่น `MEGA Code Clock DB`

### 2. ติดตั้ง Apps Script
1. ที่แถบเมนูด้านบน ไปที่ **ส่วนขยาย (Extensions) > Apps Script**
2. ลบโค้ดเริ่มต้นทั้งหมดในไฟล์ `Code.gs` ออก
3. เปิดไฟล์ [`google-apps-script/Code.gs`](file:///d:/cprttk/google-apps-script/Code.gs) ในโปรเจกต์นี้ คัดลอกโค้ดทั้งหมดแล้วนำไปวางใน Apps Script
4. กด **บันทึก (Ctrl + S)**

### 3. เผยแพร่เว็บแอป (Deploy Web App)
1. กดปุ่มสีน้ำเงิน **"การทำให้ใช้งานได้" (Deploy) > "การทำให้ใช้งานได้ใหม่" (New deployment)**
2. คลิกเลือกประเภทเป็น **"เว็บแอป" (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description)**: `MEGA Code Clock API`
   - **ปฏิบัติการในฐานะ (Execute as)**: `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: **`ทุกคน (Anyone)`** *(สำคัญมาก! ต้องเลือก Anyone เพื่อให้เว็บสามารถส่งข้อมูลเข้าชีตได้)*
4. กดปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
5. กดยอมรับสิทธิ์การเข้าถึง (Authorize Access)
6. คัดลอก **URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`

### 4. นำ URL มาใส่ในเว็บ
1. เปิดหน้าเว็บ MEGA Code Clock
2. คลิกที่ปุ่ม **"⚙️ เชื่อมต่อ Google Sheets"** ที่แถบเมนูด้านบน
3. นำ URL ที่คัดลอกมาวางในช่อง แล้วกด **"ทดสอบ"**
4. เมื่อขึ้นเครื่องหมาย `✓ เชื่อมต่อสำเร็จ` ให้กด **"บันทึก URL"**
5. ข้อมูลการลงเวลาทั้งหมดจะถูกบันทึกลง Google Sheets ทันที!
