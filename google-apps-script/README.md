# ☁️ Google Sheets API Backend Setup Guide

คู่มือการติดตั้งและเชื่อมต่อ **Google Sheets** เพื่อใช้เป็นฐานข้อมูลอย่างถาวรสำหรับ **MEGA Code Clock**

---

## 📁 โครงสร้างไฟล์ในโฟลเดอร์นี้

- **`Code.gs`**: สคริปต์ Google Apps Script (GAS) สำหรับประมวลผลคำขอ GET/POST จากเว็บแอป
- **`appsscript.json`**: ไฟล์ Manifest กำหนดค่า Timezone (`Asia/Bangkok`), Runtime V8, และสิทธิ์การเข้าถึงแบบสาธารณะ (Anyone)

---

## 🛠️ ขั้นตอนการติดตั้ง (ใช้เวลา 2 นาที)

### ขั้นตอนที่ 1: สร้าง Google Sheets
1. เปิดเบราว์เซอร์ไปที่ [sheets.new](https://sheets.new) เพื่อสร้างสเปรดชีตเปล่าขึ้นมาใหม่
2. ตั้งชื่อไฟล์ตามต้องการ เช่น `MEGA Code Clock DB`

### ขั้นตอนที่ 2: ติดตั้ง Apps Script
1. ที่แถบเมนูด้านบนของ Google Sheets คลิกที่ **ส่วนขยาย (Extensions)** > **Apps Script**
2. ลบโค้ดเริ่มต้นทั้งหมดในไฟล์ `Code.gs` ออก
3. คัดลอกโค้ดทั้งหมดจากไฟล์ [`google-apps-script/Code.gs`](./Code.gs) ไปวางแทนที่
4. กดบันทึก (Ctrl + S หรือคลิกไอคอนแผ่นดิสก์)

### ขั้นตอนที่ 3: เผยแพร่เว็บแอป (Deploy Web App)
1. คลิกปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. คลิกที่ไอคอนเฟือง ⚙️ ด้านซ้าย เลือกประเภทเป็น **เว็บแอป (Web app)**
3. กำหนดค่าดังนี้:
   - **คำอธิบาย (Description):** `MEGA Code Clock API v1`
   - **ปฏิบัติการในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **`ทุกคน (Anyone)`** *(สำคัญมาก ต้องเลือก Anyone เพื่อให้เว็บแอปสามารถส่งข้อมูลได้)*
4. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. หากมีหน้าต่างขอสิทธิ์ ให้คลิก **ให้สิทธิ์การเข้าถึง (Authorize access)** > เลือกบัญชี Google ของคุณ > คลิก **ขั้นสูง (Advanced)** > คลิก **ไปยังโปรเจกต์ (Go to ... unsafe)** > คลิก **อนุญาต (Allow)**
6. คัดลอก **URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec` เช่น:
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```

### ขั้นตอนที่ 4: เชื่อมต่อเข้ากับ Next.js / เว็บไซต์
เลือกทำวิธีใดวิธีหนึ่ง:

#### วิธี A: กำหนดในไฟล์ `.env.local` (แนะนำ - ปลอดภัยและซิงค์อัตโนมัติไม่ต้องกรอกซ้ำ)
สร้างไฟล์ `.env.local` ในโฟลเดอร์รากของโปรเจกต์:
```env
GOOGLE_SHEETS_WEBAPP_URL=https://script.google.com/macros/s/AKfycb.../exec
```

#### วิธี B: กรอกผ่านหน้าเว็บ (UI)
1. เปิดหน้าเว็บ MEGA Code Clock
2. คลิกปุ่ม **"⚙️ เชื่อมต่อ Google Sheets"** บนแถบ Header ด้านบน
3. วาง Web App URL ที่ได้ลงในช่อง แล้วกด **"ทดสอบ"**
4. เมื่อขึ้นข้อความสีเขียวว่าเชื่อมต่อสำเร็จ ให้กด **"บันทึก URL"**

## 📊 โครงสร้างคอลัมน์ใน Google Sheets (สร้างให้อัตโนมัติ)

เมื่อมีการส่งข้อมูลครั้งแรก สคริปต์จะสร้างแท็บชื่อ `TimeRecords` พร้อมตกแต่งหัวตารางสี Navy Blue ให้โดยอัตโนมัติ:

| คอลัมน์ | ชื่อหัวตาราง | คำอธิบาย | ตัวอย่างข้อมูล |
| :---: | :--- | :--- | :--- |
| **A** | ID | รหัสเฉพาะของรายการ | `REC_1730720400000_123` |
| **B** | ลำดับ | ลำดับที่ | `1` |
| **C** | วันที่ | วันที่บันทึก (YYYY-MM-DD) | `2026-11-04` |
| **D** | เวลา | เวลาที่กดบันทึก (HH:mm:ss) | `18:30:15` |
| **E** | รอบ (Round) | ชื่อรอบการปฏิบัติงาน | `รอบที่ 1` |
| **F** | ชื่อ | ชื่อจริง | `สมชาย` |
| **G** | นามสกุล | นามสกุล | `ใจดี` |
| **H** | ชื่อ-นามสกุล | ชื่อเต็ม | `สมชาย ใจดี` |
| **I** | รหัส/สังกัด | รหัสประจำตัว หรือหน่วยงาน | `EMP-001` |
| **J** | ประเภทการบันทึก | เข้างาน, เช็คพอยท์, ออกงาน, เหตุการณ์ | `เข้างาน` |
| **K** | เวลาที่ใช้ในรอบ (Elapsed) | เวลาสะสมตั้งแต่เริ่มรอบ | `01:45` |
| **L** | หมายเหตุ | ข้อมูลเพิ่มเติม | `ตรวจเช็คความพร้อม` |
| **M** | เวลาที่ส่งเข้าชีต (Sync Time) | เวลาที่ระบบบันทึกลง Google Sheets | `2026-11-04 18:30:16` |

## 🧪 การทดสอบ Endpoint (API Actions)

- **GET `?action=ping`**: ตรวจสอบสถานะการทำงานของสคริปต์และจำนวนแถวปัจจุบัน
- **GET `?action=getAll`**: ดึงข้อมูลประวัติทั้งหมดในรูปแบบ JSON
- **POST `{ "action": "add", "record": { ... } }`**: เพิ่มแถวใหม่
- **POST `{ "action": "batchAdd", "records": [ ... ] }`**: เพิ่มหลายแถวพร้อมกัน (Bulk Sync)
- **POST `{ "action": "update", "id": "REC_...", "record": { ... } }`**: อัปเดตข้อมูลตาม ID
- **POST `{ "action": "delete", "id": "REC_..." }`**: ลบข้อมูลตาม ID
